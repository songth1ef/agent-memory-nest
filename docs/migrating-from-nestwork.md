# Migrating from Nestwork

Nestwork was renamed to agent-memory-nest and simplified in protocol 4.0. Your
memory, rules and history carry over unchanged; what changes is the protocol
layer, a few file names and the tool installs on each machine.

## What changed

| Before (Nestwork, protocol 3.x) | Now (agent-memory-nest, protocol 4.0) |
|---|---|
| `scripts/hooks/nestwork.sh`, `~/.nestwork_host`, `~/.nestwork_id_<tool>`, `NESTWORK_*` | `scripts/hooks/agent-nest.sh`, `~/.agent_nest_host`, `~/.agent_nest_id_<tool>`, `AGENT_NEST_*` |
| Limits table in `AGENTS.md` plus `queen/limits.md` | `split` and `resident` settings in `config.md` |
| `agents/<host>/settings.json` | `agents/<host>/config.md` |
| Topic index generated by `memory-index.py` between markers | Agents keep `memory.md` as a plain index; `check-nest.py` checks it at the end of each turn |
| Six-level priority chain | Four levels: `queen/` > `shared/` > `agents/` > `projects/` and `workflow/` |
| Local history sync to orphan branches, claude-mem export | Removed |
| No push guard | `scripts/git-hooks/pre-push` refuses pushes to the public template |

## Steps

Run these in your private nest, on one machine, with a clean working tree.

1. **Point the upstream at the new template and pull the protocol.**

   ```bash
   git remote set-url upstream https://github.com/songth1ef/agent-memory-nest.git 2>/dev/null \
     || git remote add upstream https://github.com/songth1ef/agent-memory-nest.git
   git fetch upstream main
   git archive upstream/main -- scripts/maintenance/update.sh | tar -x
   bash scripts/maintenance/update.sh
   ```

2. **Delete the files 4.0 no longer uses.** `update.sh` adds and replaces files but never
   deletes them. Keep `scripts/hooks/nestwork.sh` for now: machines that are not
   reinstalled yet still call it.

   ```bash
   git rm -q --ignore-unmatch scripts/hooks/export-claude-mem.sh \
     scripts/hooks/sync-local-history.* scripts/hooks/launch-local-history-sync.py \
     scripts/hooks/snapshot-local-orphan.sh scripts/maintenance/memory-index.py \
     scripts/maintenance/check-resident.py schemas/nestwork.config.schema.json
   ```

3. **Move your settings.** If you had `queen/limits.md`, put the numbers into `config.md`
   (copy `config.example.md` first). Turn each `agents/<host>/settings.json` into an
   `agents/<host>/config.md` with the same front-matter format, or delete it if it only
   held local-history options.

4. **Check the layout and commit.**

   ```bash
   python3 scripts/maintenance/check-nest.py
   git commit -m "chore: migrate to agent-memory-nest protocol 4.0"
   git push
   ```

   Old topic-index markers in `memory.md` can stay; the links between them still count
   as the index.

5. **Reinstall on every machine.** Pull, then run the installer for each tool. The
   installer reads the old identity files, so each machine keeps its host and agent ids,
   and it replaces the old hooks and startup blocks instead of adding a second copy.

   ```bash
   git -C ~/your-nest pull
   bash ~/your-nest/scripts/install/claude.sh   # and codex.sh, kimi.sh, ...
   ```

   For Codex, run `/hooks` once afterwards to trust the changed hooks.

6. **Remove the last old hook script** once every machine has been reinstalled:

   ```bash
   git rm -q scripts/hooks/nestwork.sh
   git commit -m "chore: remove the Nestwork hook script" && git push
   ```

   Until then, machines that still run the old hooks keep syncing through it. The old
   SessionEnd hooks for local history and claude-mem point at scripts deleted in step 2,
   so they print an error at session end until that machine is reinstalled; memory sync
   is not affected.
